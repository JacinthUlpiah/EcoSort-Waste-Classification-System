# EcoSort

EcoSort is a real-time AI-based waste classification system that uses computer vision to identify common household waste and provide disposal recommendations.

## Project Description

The system allows users to upload or capture an image of a waste item. A trained deep learning model classifies the item and displays its predicted category, confidence score, and recommended disposal category.
